# Skills

A collection of [Agent Skills](https://agentskills.io) tested with Claude Code and Codex.

## Available Skills

| Skill | Description |
|-------|-------------|
| [workflow](workflow/) | Select and compose multi-agent workflow topologies for complex coding, research, investigation, review, and implementation tasks. |

## Installation

```bash
bunx skills add nicosuave/skills
```

Install only the workflow skill:

```bash
bunx skills add nicosuave/skills/workflow
```
